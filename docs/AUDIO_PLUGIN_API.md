# Audio Plugin API

## Manifest

`plugins/audio/manifest.json`:

```json
{
  "schemaVersion": 1,
  "plugins": [
    {
      "id": "minimal-impact",
      "name": "Minimal Impact",
      "module": "./minimal-impact/audio.js"
    }
  ]
}
```

Select the ID in `game-config.json`:

```json
"plugins": {
  "audio": "minimal-impact"
}
```

## Module contract

```js
export function createAudioTheme({ config, teams, gameConfig, options, random }) {
    return {
        id: 'my-audio-theme',
        name: 'My Audio Theme',
        mapEvent(event) {
            return [];
        }
    };
}
```

`mapEvent(event)` must be deterministic and return an array of cue descriptors. Do not call `Math.random()`. Noise generation is automatically seeded from the event sequence and cue offset.

## Event structure

```js
{
  sequence: 42,
  frame: 911,
  type: 'shoot',
  payload: {
    botId: 'cyan-2',
    teamId: 'cyan',
    x: 380,
    y: 850,
    worldWidth: 1080,
    worldHeight: 1920
  }
}
```

The event frame is authoritative. Offline audio time is:

```text
event seconds = event.frame / (targetFps × timeScale)
```

Current event types:

```text
match-start
shoot
projectile-hit
melee-hit
shield-hit
projectile-wall
powerup-collect
food-collect
zone-stage
zone-damage
bot-death
match-end
```

Audio plugins can ignore any event.

## Tone cue

```js
{
  type: 'tone',
  start: 0,
  duration: 0.08,
  frequency: 680,
  endFrequency: 460,
  gain: 0.15,
  waveform: 'square',
  pan: -0.4,
  attack: 0.002,
  release: 0.05
}
```

Supported waveforms:

```text
sine
square
triangle
sawtooth
```

## Noise cue

```js
{
  type: 'noise',
  start: 0,
  duration: 0.06,
  gain: 0.08,
  pan: 0.2,
  attack: 0.001,
  release: 0.04,
  color: 'high',
  seedOffset: 17
}
```

Supported noise colors:

```text
white
low
high
```

`seedOffset` differentiates several noise cues generated by the same event.

## Live and recorded consistency

Both paths use the same `mapEvent()` output:

```text
Game event -> audio plugin cue descriptors
                         |-> Web Audio live synthesizer
                         |-> Offline PCM/WAV synthesizer -> FFmpeg MP4
```

The synthesis implementations are separate, but cue start times, durations, frequency envelopes, gain envelopes, pan, and deterministic noise seed are shared. Therefore recorded audio is frame/sample aligned with the recorded simulation rather than captured from an imprecise speaker loopback.

Browser autoplay rules require one click or key press before live sound can start. The frame-by-frame recorder does not require audio-device access.
